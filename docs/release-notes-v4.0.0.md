## 这版变了什么

从「按一次热键翻一句话」扩到「盯着看也行、专有名词不打架、日语也能认」。

**多语言**

- 源语言默认**自动识别**（本地按字符集判断 + 提示词让模型自判），目标语言可选简/繁中文、英、日、韩、俄
- **日语能认假名了**：随包带一份日语识别模型（约 9MB），设置 →「翻译服务」→「识别语言」选「日语」即可；韩语/俄语走 Windows 的 OCR 语言包，缺包时状态栏会告诉你怎么装
- 中英混排的行（`You are one step closer ... in已将截图保存为1.png`）以前整行跳过，现在中文原样保留、英文照翻

**连续翻译 · 实时（守护选区）**

- `Alt+c`（或小窗标题行的「实时」按钮）开始盯住选区：定时抓图 + OCR，**只有文字真的变了才发翻译请求**
- 连续多次没变化自动降频；间隔 / 最短请求间隔 / 相似度阈值可在设置里调

**区域更细**

- 每个区域可绑**专属热键**（按一下只翻这一块）+ 区域**类型**（物品区用通用译名、不整理成段；字幕区口语化、把断行接回整句）
- 物品和字幕混在一次取词里时，自动分成两批请求，各带各的提示词
- 「选区」页加了「框选新区域」按钮，不用记热键也能直接去框

**专有名词不再前后打架**

- 模型翻译时顺手返回本批的人名/地名表，应用攒成**自动术语表**，下一批自动带上——同一个名字固定一种译法
- 术语表只在本机留 **24 小时**，过期自动清；设置里能看到条数并一键清空
- 术语表**按需注入**：只把本批真的出现过的词塞进提示词（带 OCR 容错，`P0ISON`、`MychaeI` 也能命中），表再长也不撑提示词

**改译文并记住**

- 小窗译文框可以直接编辑，点「保存修正」→ 写进本地缓存（以后同一句不再问模型）+ 短名词记进术语表；历史里那条同步更新

**OCR 与界面**

- 画面发灰时自动增强对比度；被切碎的行（含同一行被切成左右碎片）在翻译前拼回整句
- 界面按钮换成线性图标并加了悬停/按下反馈；翻译时转圈 + 底部细进度条；历史浮层从右侧滑入

## 下载

`mchanhua-4.0.0-win64.zip`（约 113 MB，解压即用，无需 Python）

1. 解压到任意目录；
2. 双击 `mchanhua.exe`；
3. 小窗右下角「设置」→「翻译服务」填 API Key →「测试连接」→「保存并应用」；
4. 游戏里按 `Alt+v` 框住要翻译的地方（`Enter` 存一个、`Esc` 结束），之后按 `Ctrl+Alt` 一次翻完。

> 第一次用建议看一下包里的 `HOW-TO-USE.txt`。

## 默认热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt` | 翻译所有已保存的区域 |
| `Alt+/` | 框选一块并立刻翻译（不保存） |
| `Alt+m` | 全屏翻译 |
| `Alt+s` | 翻译剪贴板里的图片 |
| `Alt+v` | 框选并保存区域 |
| `Alt+c` | 连续翻译（实时）开关 |
| `Ctrl+Alt+W` | 显示 / 隐藏小窗 |

热键都能在设置里改，也支持"只按 Ctrl+Alt 这种纯修饰键组合"。

## 说明

- 只读屏幕：**不改动游戏文件、不注入进程**；OCR 全部在本机跑，只有翻译时把识别出的文字发给所选服务商
- 配置与日志在 `%APPDATA%\mchanhua\`（卸载不会删）
- 完整改动见 [CHANGELOG](../CHANGELOG.md)，设计与取舍见 [docs/v4-总览.md](v4-总览.md)

# mchanhua v1 总览（存档）

## 定位

给自己玩游戏时看懂英文内容：**屏幕取词 → 翻译 → 小窗显示**。
明确不做汉化补丁、不修改游戏文件、不注入游戏进程。

## v1 已实现

| 能力 | 说明 |
|---|---|
| 热键取词 | 截取屏幕区域（mss）→ OCR → DeepSeek 翻译 → 置顶小窗显示原文与译文 |
| 取词区域 | 默认跟随光标（`-280,-20,560,440`），也可按热键拖拽框选一次长期使用 |
| 图片入口 | 小窗「打开图片」按钮、`Alt+S` 翻译剪贴板图片、CLI `translate-image` |
| 文本入口 | CLI `translate-text`，直接验证提示词效果（不经过 OCR） |
| OCR 后端 | RapidOCR（默认，质量优先）与 Windows 自带 OCR（快、零依赖） |
| 翻译质量 | JSON 结构化逐行对齐、内置 Minecraft 术语表、格式串保护、**OCR 乱码二次纠错** |
| 缓存 | sqlite 按「模型+提示词版本+原文」哈希缓存，同句不重复计费 |
| 可观测性 | 文件日志 + 心跳 + 看门狗（界面卡住自动 dump 全线程堆栈） |
| 启动方式 | 双击 `启动.cmd`（纯 ASCII，自动切目录、用虚拟环境 Python） |

## 使用

```powershell
notepad D:\mchanhua\config.local.toml      # 填 [translate] api_key
D:\mchanhua\启动.cmd                        # 双击也行
```

热键（`config.local.toml` 的 `[hotkeys]`）：

| 热键 | 作用 |
|---|---|
| `ctrl+alt` | 取词翻译（纯修饰键，按下即触发） |
| `alt+s` | 翻译剪贴板里的图片 |
| `ctrl+alt+r` | 框选取词区域 |
| `ctrl+alt+x` | 退出 |

## 关键设计决策（都有实测依据）

- **OCR 引擎默认 RapidOCR**：真实游戏截图上 CER 3.6%~5%，Windows OCR 是 21%~42%。
- **像素字体/3D 文字识别不可靠**：默认位图字体 CER 0.87~1.00，Unifont 同样；换成防锯齿 TTF 且字高 ≥28px 后降到 6%。详见 `docs/ocr-findings.md`。
- **中英混排要过滤**：识别结果里已含中文的行原样保留，避免"磁石"被再翻一次。
- **线程模型**：热键回调只往队列丢"一次性任务"；界面线程执行任务；工作线程跑 OCR+翻译；同一时刻只允许一次取词。

## 已知限制

- 世界内的 3D 立体文字（墙上、告示牌）识别率低，只能靠二次纠错救回一部分。
- 聊天栏小字、带淡入动画的字幕不可靠；物品 tooltip、任务书这类平面大字的准确率高。
- 小窗是独立窗口：游戏需窗口化/无边框全屏，独占全屏看不到译文。
- 依赖网络调用 DeepSeek（约 1~3 秒/次），首次翻译有延迟，命中缓存后为 0ms。

## 踩过的坑（v2 别重犯）

1. **消息队列自喂**：drain 执行任务时又往同一队列放消息 → 主线程死循环、窗口"未响应"。现在消息携带一次性任务，且有每轮条数上限。
2. **sqlite 线程亲和性**：连接在 A 线程创建、B 线程使用会直接报错。现在 `check_same_thread=False` + 互斥锁。
3. **沙箱身份交叉**：在 Codex 沙箱里创建的 `.git` 目录属主是沙箱账号，会导致沙箱初始化改 ACL 失败；测试临时目录同理（改用仓库内自带夹具 `workdir`）。
4. **纯修饰键热键**：`ctrl+alt` 按下即触发，会与所有 `ctrl+alt+X` 冲突。
5. **keyboard 库忽略自己注入的按键**：无法用 `keyboard.send()` 自动验证热键是否生效，只能人工按。
6. **批处理编码**：含中文的 UTF-8 `.cmd` 会被 cmd.exe 误解析，启动脚本必须保持纯 ASCII。

## 测试与工具

- `pytest`：104 项测试，覆盖几何/配置/采集/OCR 结果整理/翻译层/缓存/流水线/控制器/界面/跨线程/日志。
- 走真实 socket 的 DeepSeek 接口集成测试（本地假服务器，不访问外网）。
- OCR 度量工具：`tools/measure_ocr.py`、`tools/make_sample.py`（从本机客户端 jar 读取真实字体纹理，不把素材入库）。

## 代码结构

```
mchanhua/
  geometry.py        区域模型、DPI 感知、坐标换算
  capture.py         屏幕采集（mss/Pillow）、剪贴板图片
  ocr/               OCR 后端（base/windows/rapidocr）
  translate/         DeepSeek / 缓存 / 格式串保护 / 术语表
  pipeline.py        OCR → 翻译 的纯逻辑
  ui/                小窗（window.py）、框选遮罩（region_picker.py）
  app.py             控制器（热键、队列、工作线程）
  diagnostics.py     心跳与看门狗
  logging_setup.py   日志与异常钩子
  cli.py             命令行入口
```

# v3 打包说明

## 产物

```
dist\mchanhua\mchanhua.exe      8.2 MB（启动器）
dist\mchanhua\                 232 MB（整包，含 OCR 模型与依赖）
```

双击 `mchanhua.exe` 即可运行：**没有黑窗口**（打包时 `console=False`），
启动后直接出现取词小窗，右下角「设置」按钮进入设置界面。

## 一键打包

双击 `打包.cmd`（跑测试 → 生成图标 → PyInstaller 打包），或手动：

```powershell
cd /d <项目目录>
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean mchanhua.spec
```

## 打包时踩过的坑（都已修好）

1. **`_ctypes` 加载失败**：Miniconda 的扩展模块依赖 `Library\bin` 里的 DLL
   （`ffi.dll`、`sqlite3.dll`、`libssl-3-x64.dll`、`libexpat.dll`、`tcl86t.dll` …），
   PyInstaller 默认不收。现在 `mchanhua.spec` 会用 pefile 自动分析 `DLLs\*.pyd` 的依赖并补齐（共 19 个）。
2. **RapidOCR 子模块缺失**：它用字符串动态导入 `ch_ppocr_v3_det` 等模块，
   静态分析看不到 → 现在用 `collect_submodules("rapidocr_onnxruntime")` 全量收集。
3. **GUI 程序没有控制台**：`print()`/`sys.stdout` 为 None 会导致崩溃 →
   启动时把 stdio 兜底到空设备，日志只走文件。
4. **启动失败看不到原因**：打包后新增 `%APPDATA%\mchanhua\logs\startup-error.log`，
   启动阶段崩溃会写完整堆栈。
5. **路径**：打包后没有项目目录 → 配置、日志、缓存、调试文件统一放
   `%APPDATA%\mchanhua\`（可用环境变量 `MCHANHUA_HOME` 覆盖）。
6. **单实例锁**：同一时间只允许一个实例，避免多开导致热键重复触发、日志互相覆盖。

## 设置界面

右下角「设置」按钮（或 `mchanhua.exe settings`）打开：

| 标签页 | 内容 |
|---|---|
| 翻译服务 | 服务商下拉（DeepSeek / OpenAI / Kimi / 通义 / 智谱 / 硅基流动 / Ollama / 自定义）、接口地址、模型名、**API Key 独立输入框**（可切换显示）、**测试连接** |
| 热键 | 6 个动作都能改：点输入框直接按组合键录进去，也支持手输；保存时检查重复与前缀冲突 |
| 界面外观 | 窗口宽高、原文字号、译文字号、内边距、透明度、背景/面板/文字/强调色（带颜色选择器） |

热键与翻译服务**保存后立即生效**；界面外观重启后生效。

# v2 改动说明

v2 的三条需求与实现方式：

## 1. 取词改用「自定义选区」，并且要保存下来

- 取词区域的优先级改为：**已保存的自定义选区 > 跟随光标 > 上次框选**。
- 按 `alt+v` 框选一次之后，选区会**写入配置文件**（`config.local.toml` 的 `[regions.fixed] custom = "x,y,w,h"`），
  重启程序依然生效。
- 保存失败（例如配置文件只读）时界面会提示"写入配置失败，重启后不保留"，选区当次仍然有效。
- 选区超出当前屏幕（换显示器/改分辨率）时会被忽略并记日志，自动回退到跟随光标。

## 2. `Alt+/`：框选并直接翻译（一次到位）

- 新增热键动作 `translate_region`，默认 `alt+/`。
- 按下后弹出框选，松开鼠标**立即翻译这块区域**，同时把选区保存为自定义选区。
- 取消框选（按 Esc 或没拖动）时什么也不做，只提示"已取消框选"。

## 2.1 `Ctrl+Alt` 与 `Alt+V` 的联动

- `Alt+V` 只负责**框选并保存**自定义选区（不翻译）。
- 保存之后按 `Ctrl+Alt`，就用这个选区去翻译——两个热键共用同一个区域记录，
  重启程序后依然有效（选区写在配置文件里）。
- 如果还没框选过，`Ctrl+Alt` 会回退到"跟随光标"的区域，并提示先框选一次。

## 3. `Alt+m` 全屏翻译

- 新增热键动作 `translate_fullscreen`，默认 `alt+m`。
- 抓取整块屏幕（主显示器全尺寸）后 OCR + 翻译，结果全部显示在小窗里。
- 整屏识别出来的行可能很多，设了上限 `FULLSCREEN_MAX_LINES = 60`：
  超出的行会被跳过并在状态栏提示"全屏共识别 N 行，只翻译前 60 行"。
- 小窗的译文区加了滚动条，方便查看全屏结果。

## 界面变化

按钮改成两行，便于区分主次：

| 行 | 按钮 |
|---|---|
| 第一行 | 翻译选区（=Ctrl+Alt） / 框选并翻译（=Alt+/） / 全屏翻译（=Alt+m） |
| 第二行 | 只框选（=Alt+V） / 打开图片 / 清空 / 退出 |

## 热键总览

| 热键 | 作用 |
|---|---|
| `ctrl+alt` | 翻译已保存的自定义选区 |
| `alt+/` | 框选并立即翻译（顺带保存该选区） |
| `alt+m` | 全屏翻译 |
| `alt+s` | 翻译剪贴板里的图片 |
| `alt+v` | 只框选并保存选区（配合 `ctrl+alt` 使用） |
| `ctrl+alt+x` | 退出 |

## 顺带修掉的问题

- `save_config()` 之前默认写到 `%APPDATA%\mchanhua\config.toml`，与 `load_config()` 的解析顺序不一致，
  会把配置写到用户找不到的地方；现在统一为"显式路径 > 本次加载来源 > 默认路径"。
- 热键校验的符号类里 `-` 意外构成字符范围，导致 `alt+/` 被判为非法按键；现在逐字符转义。
